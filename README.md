# NSB-AI

A private document-based AI assistant for the National Signals Bureau, built on a local RAG (Retrieval-Augmented Generation) pipeline.

## Architecture

- **LLM:** phi3:mini via Ollama (fully offline)
- **Embeddings:** all-MiniLM-L6-v2 via HuggingFace
- **Vector store:** ChromaDB (local)
- **API:** FastAPI with streaming
- **UI:** Streamlit

## Project Structure

nsb-ai/
├── docs/          # NSB reference documents (not tracked in git)
├── vectorstore/   # Auto-generated by ingest.py (not tracked)
├── rag.py         # Retrieval chain
├── api.py         # FastAPI backend
├── ingest.py      # Document ingestion pipeline
├── ui.py          # Streamlit frontend
└── requirements.txt

## Setup

1. Install dependencies

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

2. Add documents to `./docs` and run ingestion

```powershell
python ingest.py
```

3. Start the API

```powershell
uvicorn api:app --port 8000
```

4. Start the UI

```powershell
streamlit run ui.py
```

## Requirements

- Python 3.10+
- [Ollama](https://ollama.com) with `phi3` pulled
- 8GB RAM minimum
