# NSB-AI

A private document-based AI assistant for the National Signals Bureau, built on a local RAG (Retrieval-Augmented Generation) pipeline.

## Architecture

- **LLM:** llama3.1 via Ollama (fully offline)
- **Embeddings:** nomic-embed-text-v1.5 via HuggingFace
- **Vector store:** ChromaDB (local)
- **API:** FastAPI with streaming
- **UI:** Streamlit

## Project Structure
```
nsb-ai/
├── docs/          # NSB reference documents (not tracked in git)
├── vectorstore/   # Auto-generated by ingest.py (not tracked in git)
├── local_models/  # (not tracked in git)
├── rag.py         # Retrieval chain
├── api.py         # FastAPI backend
├── ingest.py      # Document ingestion pipeline
├── ui.py          # Streamlit frontend
└── requirements.txt
```
## Setup

1. Install dependencies

```powershell
irm https://ollama.com/install.ps1 | iex
ollama pull llama3.1
irm https://astral.sh/uv/install.ps1 | iex
uv sync
git clone https://huggingface.co/nomic-ai/nomic-embed-text-v1.5 ./local_models/nomic-embed-text-v1.5

```

2. Add documents to `./docs` and run ingestion

```powershell
uv run ingest.py
```

3. Start the API

```powershell
uv run uvicorn api:app --port 8000
```

4. Start the UI

```powershell
uv run streamlit run ui.py
```

## Requirements

- Python 3.14.3+
- [Ollama](https://ollama.com) with `llama3.1` pulled
- 8GB RAM minimum
